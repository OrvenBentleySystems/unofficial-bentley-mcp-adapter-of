# STAAD Assistant — Microsoft 365 Copilot → OpenSTAAD MCP → STAAD.Pro

A Microsoft 365 Copilot **declarative agent** ("STAAD Assistant") with an **MCP plugin** that reads live
STAAD.Pro runtime status from this workstation through an authenticated, read-only gateway in front of
the unmodified Bentley **OpenSTAAD MCP** server.

```
M365 Copilot (browser) ─► STAAD Assistant (declarative agent, plugin v2.4 RemoteMCPServer, Entra SSO)
   ─► https://ck8d1ltp-18130.asse.devtunnels.ms/mcp   (persistent dev tunnel "staad-assistant-gw")
   ─► 127.0.0.1:18130  STAAD MCP gateway (this repo: Entra JWT validation + 3-tool allowlist + audit)
   ─► stdio child: openstaad-mcp v1.3.0 (Bentley, pinned)  ─► OpenSTAAD COM ─► running STAAD.Pro
```

Users must **select STAAD Assistant** in Microsoft 365 Copilot; this does not add tools to generic Copilot chat.

**Status: PARTIALLY PROVEN / BLOCKED** — local and HTTPS paths are verified; provisioning is blocked
because the Bentley tenant does not allow this user to create the Entra app registration that
Entra SSO requires. See [docs/RUNBOOK.md](docs/RUNBOOK.md#blocker-entra-app-registration) and
[docs/TEST-EVIDENCE.md](docs/TEST-EVIDENCE.md).

## Layout

| Path | Purpose |
|---|---|
| `agent/` | Agents Toolkit project (generated by `atk new -c declarative-agent-with-action-from-mcp`), edited: Entra app manifest, pinned tools, instructions, no tenant `publish` stage |
| `adapter/` | Python gateway (`staad_mcp_gateway`), unit tests, live probes, `uv.lock` |
| `scripts/` | `preflight`, `start`, `stop`, `validate`, `provision` (PowerShell 7) |
| `docs/` | Decisions, security, runbook, evidence, limitations |
| `.env.example` | Local configuration names (copy to `.env.local`) |

## Quick use (after the blocker is resolved)

```powershell
pwsh scripts\preflight.ps1      # read-only gate check
pwsh scripts\provision.ps1      # dev-user sideload only
pwsh scripts\start.ps1          # gateway + tunnel
# Browser: https://m365.cloud.microsoft/chat → Agents → "STAAD Assistantdev"
pwsh scripts\stop.ps1           # removes public reachability
```
