# Security policy

This is unsupported community software. Do not send vulnerability details,
credentials, client files, or project data through a public issue.

Use GitHub's **Security** tab and **Report a vulnerability** to submit a private
report after this repository is published. If private vulnerability reporting
is unavailable, contact the repository maintainer through a private channel
listed on their GitHub profile before sharing technical details.

Include the adapter version, Windows version, affected command, minimal
reproduction, and impact. Remove passwords, tokens, licence identifiers,
client names, coordinates, and project paths.

Supported security updates apply to the current release only. Bentley Systems,
Seequent, and the upstream MCP projects do not provide support for this
adapter.
